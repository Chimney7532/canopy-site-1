# Canopy 设计说明

## 保留的品牌

- 纸色 #f4f1ea，墨色 #171715。
- Space Grotesk 字体，原始 CANOPY 字标、眼睛与墨水转场。
- 原有英文文案、导航标签、成员分组、海报、人物照片和项目内容。

## 第二版方向

针对年轻建设者的社区网站，使用克制的字体和留白，优先呈现真实内容。视觉变化程度 6，动效程度 4，信息密度 4。

使用 design-taste-frontend 梳理排版和素材展示；使用 apple-design-interaction 的返回、触控和滚动原则；使用 apple-design-motion 的快速反馈、阻尼运动和减少动态效果原则。

## 视觉与行为

- 手机导航固定在顶部，当前栏目有明确下划线。
- 成员照片与姓名直接可见；桌面三列、手机两列，点击打开个人详情。
- 活动海报完整呈现，标题与简介始终位于海报外。
- 两个真实项目同时可浏览，不要求横向寻找第二个项目。
- 首页使用浏览器原生滚动，保留章节字标，不拦截滚轮、触屏滑动或阅读按键。
- 详情开合更快，保留可中断的墨水效果。
- 页面进入使用短距离淡入，尊重系统的减少动态效果设置。

页面入口、样式和交互已分别放入 site/index.html、public/assets/styles 和 public/assets/scripts。图片与字体独立分组，避免在入口文件中堆叠代码。
